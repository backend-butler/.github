# .github

Organisation-wide defaults for [backend-butler](https://github.com/backend-butler):

- `profile/README.md`: the org's front page.
- `SECURITY.md`, `CONTRIBUTING.md`, `SUPPORT.md`, issue and pull request templates: used by every repository that has no copy of its own.
- `.github/workflows/node-ci.yml`: the shared CI for Node projects (install with scripts blocked, signature check, audit, typecheck, tests, build).

Change a default here once instead of in every repository.
