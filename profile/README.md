# Backend Butler

An AI agent that looks after the things running in your home: Home Assistant today, and soon Proxmox, Docker, VMs and the services on them.

| Repository | What it is |
|---|---|
| [ha-addon](https://github.com/backend-butler/ha-addon) | Backend Butler as a Home Assistant app: chat with your home, with approval cards for anything beyond everyday device control |
| [ha-card](https://github.com/backend-butler/ha-card) | Butler quick card, a dashboard launcher installed with HACS |
| [backend-butler](https://github.com/backend-butler/backend-butler) | The shared core and the standalone app (early; not released yet) |
| [bb](https://github.com/backend-butler/bb) | Privilege-separated brokers, so the agent never holds a credential (not released yet) |

Found a security problem? Use **Report a vulnerability** on the affected repository's Security tab, never a public issue.
